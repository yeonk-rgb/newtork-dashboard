# 고객사 확인 필요 사항

> **2026-10-26 — 고객사 추가 답변은 받지 않기로 함.** 담당자님이 줄 수 있는 자료는 모두 공유받았으므로, 받은 자료(원본 엑셀 「경영지원 관리」, 팀별 대시보드 구분 문서, 10/14 회의 메모, 기획서, 유상AS 견적서, 담당자님 추가 요청)를 근거로 아래 질문을 **자료 기반 결정**으로 닫았다. 생산팀·서비스팀·IT 질문은 이 저장소 범위 밖이라 결정하지 않았다.
> 결정한 기준은 화면에 "적용 기준"으로 남기고(`metrics/settings.ts` `APPLIED_BASIS`), 담당자님이 다르게 원하면 설정 한 곳만 바꾼다.
