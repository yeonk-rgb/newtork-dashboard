# 경영 대시보드 확인 요청 — 생산팀·서비스팀·대표님(IT)·디자인 자료 (2026년 10월)

> **요약**
> - 경영 대시보드는 경영지원팀 화면(목표·매출·지출 입력, 미수금, 채권·채무 관리, 대시보드 그래프)이 먼저 만들어져 있고, 생산팀·서비스팀 화면은 이어서 만들 예정입니다.
> - 아래 질문은 받으실 분별로 나눠 두었습니다. 해당하는 부분만 답해 주시면 됩니다.
> - 질문은 모두 **8개**입니다 (생산팀 3 · 서비스팀 1 · 대표님 또는 IT 담당 2 · 디자인 자료 2).

**답하는 방법**: 질문마다 A·B·C 중 하나를 골라 주시거나, 맞는 선택지가 없으면 편하게 적어 주세요. 답이 없는 동안은 각 질문 아래 **"지금 적용된 방식"**대로 진행합니다.

## 생산팀

### 1. 판매처 산업분야·제품 시리즈 판매 자료는 어디서 가져올까요?

- **질문**: 대시보드 첫 화면의 "산업분야별 비중"과 "제품 시리즈별 비중" 원형 그래프에 쓸 판매 자료를, 생산팀이 올리시는 엑셀(제조내역 등)에서 가져올까요, 경영지원팀이 따로 입력할까요?
- **왜 묻는지**: 두 그래프는 화면에 자리를 만들어 두었지만, 실제 판매 자료가 아직 연결되지 않아 "샘플 데이터"라고 표시된 예시 숫자로 보이고 있습니다.
- **선택지**
  - **A. 생산팀이 올리는 엑셀에서 가져오기 (추천)** — 같은 자료를 두 번 입력하지 않아도 됩니다. 이 경우 엑셀에 판매 금액이 들어 있는지, 제품 시리즈 목록(이름)도 함께 알려 주세요.
  - **B. 경영지원팀이 매달 따로 입력하기**
- **지금 적용된 방식**: 두 그래프 모두 "샘플 데이터" 표시와 함께 예시 숫자로 보여 드립니다.

### 2. 산업분야는 어떤 분류로 나눌까요?

- **질문**: 처음 요청하신 분류(상하수도, 발전소, 가스, 오일, 석유, 민간 플랜트, 기타)와 회사 소개 자료의 사업 영역(원자력, 댐, 선박 등)이 조금 다릅니다. 어느 분류로 나눌까요?
- **왜 묻는지**: 원형 그래프의 조각과 엑셀 자료를 묶는 기준이 됩니다. 판매처마다 어느 분야인지 정하는 기준이기도 합니다.
- **선택지**
  - **A. 처음 요청하신 7개 분류 그대로 (추천)** — 원자력·댐·선박 등은 "발전소" 또는 "기타"로 묶습니다.
  - **B. 회사 소개 자료의 사업 영역에 맞춰 분류를 늘리기** (원하시는 분류 목록을 적어 주세요)
- **지금 적용된 방식**: A (7개 분류)

### 3. 원형 그래프의 "비중"은 판매 금액으로 볼까요, 판매 수량으로 볼까요?

- **질문**: 산업분야별·제품 시리즈별 비중을 판매 금액 기준으로 나눌까요, 판매 대수(수량) 기준으로 나눌까요?
- **왜 묻는지**: 비싼 제품이 적게 팔린 분야와 싼 제품이 많이 팔린 분야는 기준에 따라 순위가 바뀝니다.
- **선택지**
  - **A. 판매 금액 기준 (추천)** — 매출 목표와 같은 눈으로 볼 수 있습니다.
  - **B. 판매 수량 기준**
  - **C. 둘 다 보여 주고 바꿔 볼 수 있게**
- **지금 적용된 방식**: A (판매 금액 기준, 예시 숫자)

> 출장보고서 분석을 생산팀과 서비스팀 중 어느 팀이 맡을지는 아래 **서비스팀 1번**에서 함께 여쭙니다. 생산팀에서도 확인 부탁드립니다.

## 서비스팀

### 1. 출장보고서 분석은 어느 팀 화면에 넣을까요? (생산팀과 함께 확인 부탁드립니다)

- **질문**: 판매·유지보수 때 쓰시는 출장보고서(지금은 다우오피스의 워드 파일)를 올려서 A/S 요청 지역, 업체, 물품, 요청 사유, 유상·무상 비율, 문제 모델 순위 등을 보여 드리려고 합니다. 이 내용은 생산팀 화면과 서비스팀 화면 중 어디에 둘까요?
- **왜 묻는지**: 미팅 때 이 내용이 생산팀 항목 아래에 적혀 있었는데, 서비스팀 요청(출장 횟수, 유상/무상 비율, 지역별 지도, 교체 부품 순위 등)과 내용이 겹칩니다. 출장보고서를 누가 올리고 누가 보는지에 따라 화면과 볼 수 있는 사람이 달라집니다.
- **선택지**
  - **A. 서비스팀 화면에 두고, 서비스팀이 올리기 (추천)** — 출장 횟수·지역 지도·부품 순위와 한곳에서 볼 수 있습니다.
  - **B. 생산팀 화면에 두고, 생산팀이 올리기**
  - **C. 두 팀 모두 볼 수 있게 (올리는 팀은 한 팀으로 정해 주세요)**
- **지금 적용된 방식**: 아직 만들지 않았습니다. 답을 받은 뒤 시작합니다.

## 대표님 또는 IT 담당

### 1. 완성된 웹 화면은 어디에서 운영할까요?

- **질문**: 웹 화면을 실제로 쓰실 때, 회사 안의 서버에 설치할까요, 인터넷의 클라우드 서비스에서 운영할까요?
- **왜 묻는지**: 지금은 시험을 위해 **해외(싱가포르)에 있는 클라우드 서비스의 무료 요금제**에 올려 두었습니다. 무료 요금제는 한동안 쓰지 않으면 처음 열 때 느리고, 회사 자료가 해외 서버에 저장됩니다. 실제로 쓰실 때는 위치와 비용을 정해야 합니다.
- **선택지**
  - **A. 클라우드 서비스 유료 요금제로 옮기기 (추천)** — 서버 관리가 필요 없고, 국내 지역을 고를 수 있는지도 함께 알아봐 드리겠습니다. (월 사용료가 듭니다)
  - **B. 회사 안의 서버(또는 PC)에 설치하기** — 회사 밖에서 접속하려면 별도 설정이 필요합니다.
  - **C. 시험 기간에는 지금처럼, 실제 사용 시점에 다시 정하기**
- **지금 적용된 방식**: C (해외 클라우드 무료 요금제로 시험 중).

### 2. 로그인과 비밀번호 규칙을 이대로 써도 될까요?

- **질문**: 아래 로그인 규칙을 그대로 써도 될지, 회사 보안 규정이 따로 있으면 알려 주세요.
  - 비밀번호: 8자 이상, 영문과 숫자를 함께, 아이디·이전 비밀번호와 다르게
  - 로그인 유지: 12시간이 지나면 다시 로그인
  - 비밀번호를 5번 틀리면 10분 동안 로그인 잠금
  - 처음 받은 비밀번호는 첫 로그인 때 반드시 바꾸기, 잊어버리면 관리자가 새로 발급
- **왜 묻는지**: 회사 재무 숫자를 보는 화면이라 기본적인 잠금 규칙을 넣어 두었습니다. 사내 규정과 다르면 맞춰야 합니다.
- **선택지**
  - **A. 이대로 쓰기 (추천)**
  - **B. 회사 규정에 맞춰 바꾸기** (예: 비밀번호를 정기적으로 바꾸게 하기, 로그인 유지 시간 줄이기 — 원하시는 내용을 적어 주세요)
- **지금 적용된 방식**: A (위 규칙). 비밀번호 정기 변경은 하지 않습니다.

## 디자인 자료 (경영지원팀 또는 담당자)

### 1. 다우오피스 화면과 그래프 참고 자료를 보내 주실 수 있나요?

- **질문**: 미팅 때 말씀하신 다우오피스 화면 캡처와, 마음에 드시는 그래프 디자인 참고 자료를 보내 주실 수 있을까요?
- **왜 묻는지**: 자료를 받기 전이라, 지금은 따뜻한 회색 바탕에 흰 카드, 짙은 남색과 구리색을 포인트로 쓰는 디자인으로 만들어 두었습니다.
- **선택지**
  - **A. 자료를 보내 드리겠다 — 받은 자료에 맞춰 다듬기**
  - **B. 지금 디자인으로 충분하다 (추천, 화면을 먼저 보시고 정하셔도 됩니다)**
- **지금 적용된 방식**: B (지금 디자인)

### 2. 회사 로고 원본과 회사 지정 색이 있나요?

- **질문**: ① 로고 원본 파일(크게 키워도 깨지지 않는 파일)과 **가로로 긴 로고**가 있을까요? ② 회사에서 정해 둔 색(색상 번호)이 있을까요?
- **왜 묻는지**: 지금은 받은 로고 이미지(세로형)에서 그림과 글자를 잘라 가로로 붙여 쓰고 있습니다. 화면 색은 짙은 남색과 구리색을 쓰는데, 로고는 주황색과 짙은 회색이라 서로 다릅니다.
- **선택지**
  - **A. 로고 원본·지정 색을 보내 드리겠다 — 받은 대로 맞추기**
  - **B. 로고 색(주황색)에 맞춰 화면 색을 바꾸기**
  - **C. 지금 색 그대로 쓰기 (추천, 로고 원본만 있으면 보내 주세요)**
- **지금 적용된 방식**: C (화면 색은 지금 그대로, 로고는 세로형 이미지를 잘라 사용)
