# 프로젝트 기획서

## 한줄 요약

대표자가 현장에 상주하지 않아도 엑셀 업로드와 월말 5분 간이 입력만으로 전사 원가·이익률·가동률·자금 수지 등 핵심 지표를 한눈에 파악하고 목표를 관리하는 경영 대시보드 웹앱

## 추진 배경 (현재의 문제)

1. 데이터에 근거한 체계적 경영 및 연간 목표 수립 필요
2. 경영에 필요한 핵심 백업 데이터가 분산
3. 대표자가 한눈에 종합적으로 파악하고 즉각적인 의사결정을 내릴 수 있는 통합 모니터링 툴 부재

## 개발 목표 (PoC)

월별 각 부서에서 간단한 정보를 입력하면 AI가 분산된 데이터를 취합하고 정해진 기준에 따라 원가, 이익률, 가동률 등을 자동 산출

## 주요 기능

- **(직원)** 계정 인증 / 실적 작성(팀별) / 임시저장·수정·파일 업로드 / 입력방법 안내 표시
- **(관리자)** 누적 대시보드 및 월별 리포트(종합 및 프로젝트 원가/이익률 분석, 매입·매출·미수 현황, 3~6개월 자금수지 예측, 손익분기점(BEP) 달성률, 생산량 & 공장 가동률 산출, 수주 잔고 & 영업 파이프라인, 인당 생산성 지표) / 엑셀(CSV) 다운로드

## 활용 데이터

각 부서별 입력수치 및 업로드 자료, 그룹웨어 연동자료

## 기대효과

- **(정량)** 자료 취합·정리 월 약 8시간 x 부서 수 → 1시간 미만, 수기 작성 오류 제거
- **(정성)** 데이터 경영 체계 확립 / 분기별 OKR 추진 가능 / 근거 기반 연간 목표 수립

## 개발 구상

시스템 아키텍처 작성 → 데이터 수집 엔진 및 간이 입력폼 구축 → 입력 데이터 통합 분석 및 핵심 지표 자동 연산 → 경영 대시보드 시각화 및 리포트 자동 생성
