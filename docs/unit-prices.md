# 단가 화면 옮기기 (2026-11-05)

친구(우민영) 저장소 [alsdud8290-crypto/newtalk-dashboard](https://github.com/alsdud8290-crypto/newtalk-dashboard)의 "단가" 메뉴(`lib/pricing.js`, `public/js/pages/part-prices.js` 등) 가운데 **부품 단가** 부분을 이 저장소로 옮기고, 담당자 추가 피드백(2026-11-05)을 반영했다.

- 계산 규칙은 친구 앱 그대로 옮겼다. 피드백으로 바뀐 것과 이 저장소 규칙(숨김·변경 이력·`can()` 권한·design-guide 색)만 다르다.
- 기존 "부품·가격" 메뉴(다른 친구 저장소에서 옮긴 `svc_part`·`svc_site`·`svc_site_part_price`)는 그대로 둔다. 두 기능을 합칠지는 친구들과 정한 뒤 결정한다 (2026-11-05 사용자 결정).

## 담당자 피드백 반영

| 피드백 | 반영 |
|---|---|
| 요청처 지역 관리 → 삭제 | 친구 앱 서비스 화면이라 옮기지 않음. 이 저장소 "출장지 관리"는 그대로 (사용자 결정) |
| 견적서 업로드 → CSV 업로드(부품 단가 데이터) | 견적서 PDF 대신 **단가 데이터 업로드**(CSV·엑셀) 2종: ① 부품 단가표 ② 출장지별 단가 (사용자 결정) |
| 단가 직접 입력 탭 삭제 | 옮기지 않음 — 출장지별 단가는 업로드로만 넣는다 |
| 제품 단가·원가 탭 삭제 | 옮기지 않음 (원가·마진·커미션 계산표, 열람 기록) |
| 부품별 비교: 뉴토크 기준값 산식 삭제 | 산식 안내 상자 없음. **뉴토크 기준값 = 단가표 기준단가 그대로** (할인율·추가단가 개념 없음 — 사용자 결정) |
| 기본값을 더블클릭해 수기로 수정 | 부품별 비교 표의 "뉴토크 기준값" 칸을 두 번 누르면 입력칸 → Enter 저장 · Esc 취소 (키보드는 칸에서 Enter/F2) |
| 파트넘버 클릭 시 하단 화면의 단가표·할인·추가 줄, "이 부품만 따로" 입력 삭제 | 둘 다 없음. 하단에는 요약 5칸 + 출장지별 막대 + 단가 표만 |
| 추가: 신규 부품 등록 탭 | **부품 추가** 화면: 분류·파트넘버·품목·적용 모델·기준단가 수기 입력 + 엑셀·CSV로 여러 개 추가 |
| 추가 업로드 시 동일 내용 덮어쓰기 | 업로드에서 같은 부품(파트넘버 + 품목)·같은 단가(부품 + 출장지 + 적용 시작일)는 체크 없이 파일 값으로 덮어씀 |

## 화면 4개 (사이드바 "단가")

| 화면 | 주소 | 팀장 이상 | 팀원 |
|---|---|---|---|
| 부품별 비교 | `/service/unit-prices` (`?q=&category=&hidden=1&part=`) | 기준값 고치기, 부품·단가 숨김·복구 | 열람 |
| 출장지별 비교 | `/service/unit-prices/companies` (`?category=&company=`) | — | 열람 |
| 단가 데이터 업로드 | `/service/unit-prices/upload` | 미리보기·저장 | 열람 (버튼 비활성) |
| 부품 추가 | `/service/unit-prices/new` | 수기 추가·엑셀로 추가 | 열람 (버튼 비활성) |

권한은 `service/rules.ts`의 `serviceAbilities()` (다른 서비스 화면과 같음): 관리자·대표·경영지원팀 = 모두, 서비스팀장 = 입력·수정·숨김, 서비스팀원 = 열람 전용, 생산팀 = 403.
내려받기: 부품별 비교·출장지별 비교 [엑셀]·[CSV] (`/api/service/unit-prices/export`), 업로드 양식 CSV (`/api/service/unit-prices/template`).

## 계산 규칙 (`modules/service/unit-prices/compute.ts`)

| 항목 | 규칙 |
|---|---|
| 뉴토크 기준값 | 단가표 기준단가 그대로 (빈칸 = 미입력, 0원과 다름) |
| 출장지별 단가 | 부품마다 출장지(업체)별 가장 최근 단가 1개 — 숨김·적용 예정(오늘 이후) 제외 |
| 평균·최저·최고·최고−최저 | 위 출장지별 단가로 계산, 평균은 원 단위 반올림 |
| 기준값 대비 차이율 | (단가 − 기준값) ÷ 기준값 × 100, 소수 1자리(절반은 0에서 먼 쪽). 기준값이 없거나 0원이면 계산 안 함 |
| 크게 낮음 | 차이율 ≤ −10% (친구 앱 기본값, 화면에서 바꾸는 상자는 산식 상자와 함께 없앰 — `LOW_ALERT_RATE`) |
| 출장지별 평균 차이율 | 부품 차이율의 단순 평균, 기준값 없는 부품은 빠짐, 평균 높은 순 |
| 파트넘버 검색 | 공백·하이픈·대소문자 무시, 숫자만 치면 파트넘버 숫자만 모아 비교(0501 → MD-05-A-01) |

## 업로드 (`parse-upload.ts` → `classify.ts` → `save-upload.ts`)

- CSV(UTF-8·EUC-KR) / 엑셀 .xlsx, 최대 5MB. 미리보기는 DB 쓰기 없음, 저장할 때 서버가 파일을 다시 읽고 Serializable 트랜잭션 안에서 다시 판정한다.
- 판정: 새로 / 덮어씀(바뀐 칸 표시) / 변경 없음 / 숨긴 행과 같음(저장 안 함 — 복구 후 다시) / 오류. **오류가 1건이라도 있으면 저장하지 않는다.** 저장할 것이 없으면 안내.
- 변경 이력: 저장 1번에 요약 1건 (`area: "service"`, `screen: "service-unit-price-upload"`, `action: "IMPORT"`).

| 자료 | 머리글 (같은 뜻 다른 이름도 인식) | 같은 행 기준 |
|---|---|---|
| ① 부품 단가표 | 분류 · 파트넘버 · 품목 · 적용 모델 · 기준단가 | 파트넘버 + 품목 (공백·하이픈·대소문자 무시) |
| ② 출장지별 단가 | 파트넘버 · 품목(선택) · 출장지 · 단가 · 적용 시작일 · 비고(선택) | 부품 + 출장지 + 적용 시작일 |

- ①은 고객사 **"부품 및 단가리스트.xlsx"의 [부품] 시트를 그대로** 올려도 된다: 머리글 "구분·품목·적요·기준단가"(구분 = 파트넘버, 적요 = 적용 모델), 분류는 칸 하나만 찬 제목 행("01 현장서비스"), 대외비 안내 줄·"종류" 줄·두 번째 머리글은 건너뜀, [제품]·[Data]·[커미션] 시트는 읽지 않음. 로컬에서 확인한 결과 148개 부품·10개 분류, 오류 0건 (2026-11-05).
- **같은 부품 = 파트넘버 + 품목**인 이유: 원본에 파트넘버가 같고 품목이 다른 줄이 있다(MD-07-D-01 Transformer / Absolute Encoder — 원본 오타로 보임). 친구 앱도 `UNIQUE(part_no, name)`. ②에서 파트넘버가 같은 부품이 여럿이면 품목 칸으로 고르고, 없으면 그 행은 오류.
- 금액은 원 단위 정수(콤마·"원" 허용), 음수·소수·글자는 오류. 적용 시작일은 `2026-03-10`·`2026.3.10`·`2026/03/10`·엑셀 날짜.
