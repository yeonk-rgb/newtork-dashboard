# 10/14 고객사 미팅 내용

## 0. 기본 사항

- 현재 수금은 엑셀로 관리 중. 웹앱 상에서 입력하여 대시보드가 만들어지는 것을 희망
- 가능하면 과거 데이터 옮기는 기능도 구현. 입력만 추후에 하거나 엑셀 파일 업로드 시 반영
- 기준: 기본적으로 4분기, 월별로도 변경하여 설정하는 기능 추가
- 현재 직원 12명
- 희망 UI: 현재 사용 중인 다우오피스 참고 + 그래프 디자인 레퍼런스는 고객사가 추후 보내줄 예정

## 1. 메인 화면: 경영지원팀

- 연도의 목표매출액 (ERP 프로그램의 시각화 부재를 개선)
- 선호하는 그래프: 원형 그래프 — 현재 어디까지 차 있는지, 각 판매처가 카테고리 중 차지하는 비중(상하수도, 발전소 등), 제품 시리즈의 비중
- AI 간단한 분석 코멘트: 이번 분기의 부족한 상황, 매출 상황 등 요약. 다음 분기에 개선할 점 정리

## 2. 생산팀

- 시각화: 연간 목표 생산량 — 월/분기별, 목표 대비 몇 % / 부족치, 어떤 제품이 판매량이 높은지
- 현재 엑셀 파일로 관리 중
- 판매/유지보수 시 작성하는 '출장보고서' 파일 업로드를 통해 자동 결과 도출 (현재 다우오피스에서 워드 파일 사용 중)
  1. 내역: A/S 요청 지역, 업체명, 담당자, 물품, 요청 사유(이슈 — 메인보드 등)
  2. 전체 요청 건수, 지역별 잦은 서비스, 발생한 문제 순위, 문제 모델 순위, 전체 출장 횟수 중 무상수리와 유상수리 건 비율, 단가 변동사항(어느 정도로 측정되고 있는지)
- (참고: 출장보고서 항목은 원문에서 생산팀 아래 적혀 있으나 내용상 서비스팀 항목과 겹침 — 확인 필요)

## 3. 서비스팀

- 한국 지도상(제주도 포함) 지역별로 몇 건인지 점으로 표시 (어려울 경우 충남/부산/강릉 등 순위라도 구현)

## 4. 팀별 권한 설정

- 경영지원팀, 대표, 관리자: 모든 권한
- 관리자 페이지: 관리자가 특정 사람의 사용 권한을 필요에 따라 등록/해제, 선택 가능하게
- 생산팀/서비스팀(겸직): 각자의 팀만 열람 가능
- 각 팀의 팀장만 수정 권한, 그 외는 열람만 가능

## 5. 보안

- 처음에는 경영지원팀에서 아이디/비밀번호 일괄 부여. 이후 개인별로 비밀번호 변경 기능
- 비밀번호를 잊어버리면 관리자가 초기화
