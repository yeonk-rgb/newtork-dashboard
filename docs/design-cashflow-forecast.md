# 3~6개월 자금 수지 예측 — 설계안

> 2026-10-26 작성 — **고객 답변 없이 자료 기반 결정으로 진행 (2026-10-26, PR ⑤).** 결정으로 바뀐 점: 들어올 돈은 경영지원 관리 **외상매출금**(당월 수금예정 + 예정일, 장기 미수금 제외), 금액은 실제 주고받는 금액(부가세 포함), 통장 잔액은 월간 입력 선택 칸. 아래 원안은 PR ⑤ 때 이 기준으로 고친다.
> 기획서 "주요 기능"(`docs/01-project-overview.md`)의 "3~6개월 자금 수지 예측" 항목. 9단계 남은 일.

## 1. 지금 데이터로 예측할 수 있는 범위

| 데이터 | 예측에 쓸 수 있는 것 | 한계 |
|---|---|---|
| 미수금 건별 기록 (`Receivable.dueOn` 수금 예정일, 미수 건) | 들어올 돈 중 **예정일이 정해진 것** | 예정일이 빈 건은 날짜를 모름. 부분 수금 여부 미확인(05-11) |
| 경영지원 관리 (외상매입금·미지급비용-직원·업체, `LedgerEntry.dueOn`·`autoTransfer`) | 나갈 돈 중 **예정된 지급** | 기준년월 잔액만 있고, 지급 예정일은 칸만 있음(대부분 빈 칸 예상) |
| 월간 입력 확정 실적 (`MonthlyFinance`, `status = CONFIRMED`) | 반복되는 지출·매출의 **추정**(평균) | 실제 입출금이 아니라 실적 금액 |
| **현금(통장) 잔액** | **없음** | "잔액이 언제 부족해지는지"는 계산 불가 → 지금은 **월별 순수지(수입 − 지출)**까지만 |

앞의 1~2개월은 예정 금액이 많아 비교적 믿을 만하고, 3~6개월째는 대부분 추정이다.

## 2. 고객 답변에 따라 달라지는 것

| 질문 | 답에 따라 |
|---|---|
| 05-22 (1차 ①-1) 미수금 건별 기록 ↔ 외상매출금 하나로 합칠지 | 합치면 들어올 돈을 한 곳에서 가져온다. 합치지 않으면 지금 대시보드처럼 **미수금 건별 기록만** 쓴다 (외상매출금까지 더하면 같은 돈이 두 번 잡힘) |
| 05-24 (1차 ①-2) 경영지원 관리 총액 = 월간 입력 매입·경비·그 외 지출인지 | 같은 숫자면 경영지원 관리 총액 = "이번 달 쓴 돈 = 다음 달 나갈 돈" → 경비 평균을 따로 더하면 **이중 계산**. 연결 안 하면 경영지원 관리는 예정 지급만, 반복 지출은 월간 입력 평균 |
| 05-25 (1차 ①-3) 자동이체 | 미지급비용-업체 자동이체 금액을 지출에 넣을지 |
| 05-1 (1차 ④-1) 부가세 포함, 05-18 (1차 ④-6) 매출 기준 | 입금 기준이면 매출 ≈ 들어온 돈. 발행 기준이면 수금 시차를 반영해야 함 |
| 05-11, 05-41~46 (3차 후보) | 통장 잔액, 예정일·부분 수금, 지급 시기 기본값, 정기 지출, 지난 예정일 처리, 기간·위치 |

## 3. 예측 방식

| 방식 | 장점 | 단점 |
|---|---|---|
| 확정 예정 금액만 | 가장 정직 | 뒤쪽 달이 거의 0 → "돈이 남는다"로 잘못 읽힘 |
| 최근 3개월 평균 | 단순 | 계절 차이(4분기 집중 등) 반영 못 함 |
| 작년 같은 달 | 계절 반영 | 확정 12개월 이상 필요 — 지금은 불가 |
| **추천: 예정 금액 + 반복 항목은 최근 3개월 확정 평균** | 앞 달은 정확, 뒤 달도 0이 아님 | 추정 부분 표시가 꼭 필요 |

- 추천안의 두 부분(예정 / 추정)은 화면에서 **색 진하기로 구분**
- 작년 같은 달 방식은 확정 월이 12개월 넘게 쌓인 뒤 선택지로
- 기준·임시 설명은 BEP 처럼 **`metrics/settings.ts` 한 곳**(`cashForecast` + `provisionalNotes`)

## 4. 화면

- **위치: 경영지원 상세(`/management`) 새 섹션 "자금 수지 예측"** (`#cash-forecast`). 메인 구성은 담당자 요청대로 정한 것이라 지금은 넣지 않음 — 필요하면 나중에 요약 한 줄 (05-46)
- **모양: 막대 그래프** — 월별 흐름은 원형(도넛)으로 표현할 수 없음. 담당자 도넛 선호는 비중·구성 카드 기준(05-40 결정 기록)
  - 월별 수입·지출 막대 + 순수지 숫자
  - 아래 표: 월 / 수금 예정 / 수금 추정 / 지급 예정 / 지출 추정 / 순수지 / 누적
  - 3개월 · 6개월 전환 (기본 3개월, 05-46)
- **"예측"을 분명히**
  - 제목 옆 **"예측" 배지** (BEP "임시 기준" 배지와 같은 방식)
  - 추정 부분은 **연한 색·빗금**
  - "2026-10-26 기준" 문구
  - [계산 기준] 펼침 3~4줄
  - 첫 버전은 엑셀·AI 분석에 넣지 않음
