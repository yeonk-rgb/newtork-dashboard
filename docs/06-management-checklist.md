## 공통 (모든 항목에 해당)

- 모든 화면·Server Action의 권한 확인은 `can(user, view|edit|confirm, team)`을 거친다 — 3단계 완료 (`src/shared/auth`, 실제 로그인은 통합 시)
- 메인(`/`)·`/management`·`/admin` 서버 측 권한 확인 적용, 메뉴는 권한별 표시. 권한 해석은 고객사 확인 중 (05-14·15번)
- "확정" 시 0원 항목이 있으면 확인창 (6단계, CLAUDE.md 구현 메모)
